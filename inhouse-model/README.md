# Praman In-House Model — Phase 1: LoRA Fine-Tune

> Fine-tune Qwen2.5-7B on Indian financial data using LoRA. Output: `brain-v2-7b-indian-finance.gguf` loadable by Ollama.

## Why?

Our current Brain v2 uses general-purpose models (qwen2.5, llama3.1) with prompt engineering. They're smart but they don't "know" Indian markets — they mix up FY calendars, confuse crore/lakh, and hallucinate SEBI regulations. An in-house model fine-tuned on Indian financial data fixes all of this.

## Quick Start (3 Steps)

### Step 1: Collect Training Data

Run on your local machine (needs Next.js + Python service running):

```bash
cd inhouse-model
pip install -r requirements.txt

# Ensure Next.js + Python service are running
# (npm run dev from project root)

python scripts/01_collect_training_data.py
```

This script:
1. Fetches financial data for 50 top NSE companies via your existing `/api/company/[ticker]` endpoint
2. Fetches price stats via `/api/price-stats/[ticker]`
3. Generates 10-15 Q&A pairs per company (P/E, ROE, D/E, revenue, EPS, beta, RSI, etc.)
4. Generates 10 general Indian financial knowledge Q&A pairs (FY calendar, crore/lakh, SEBI, BRSR, etc.)
5. Shuffles and splits into training pairs (90%) + eval pairs (10%)
6. Output: `data/training_pairs.jsonl` + `data/eval_pairs.jsonl`

Expected output: ~700-800 training pairs from 50 companies + 10 general = ~710-810 pairs.

### Step 3: Load into Ollama + Test

```bash

cp brain-v2-7b-indian-finance-*.gguf inhouse-model/models/

# 2. Create the Ollama model
cd inhouse-model/models
ollama create brain-v2-7b -f Modelfile

# 3. Verify the model is loaded
ollama list
# Should show: brain-v2-7b

# 4. Test it
ollama run brain-v2-7b "What is RELIANCE's ROE?"
# Should respond with Indian formatting and cite the filing

# 5. Update coordinator.ts to use the fine-tuned model
# Edit src/lib/praman/llm/coordinator.ts:
#   Change: worker: "qwen2.5:7b" as ModelId,
#   To:     worker: "brain-v2-7b" as ModelId,

# 6. Restart the terminal
npm run dev

# 7. Type in the terminal: "What is RELIANCE ROE?"
# The Brain v2 coordinator now uses your in-house fine-tuned model
```

## Technical Details

### LoRA Parameters

| Parameter | Value | Why |
|-----------|-------|-----|
| Base model | Qwen2.5-7B | Best open-source model for instruction following |
| LoRA rank (r) | 64 | Higher = more capacity to learn domain knowledge |
| LoRA alpha | 128 | Standard: 2x rank |
| Target modules | q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj | All attention + MLP layers |
| Quantization | 4-bit (QLoRA) | Fits on single T4 GPU (16GB) |
| Learning rate | 2e-4 | Standard for LoRA |
| Max steps | 1000 | ~800 samples / batch 16 = ~50 epochs |
| Max seq length | 8192 | Qwen2.5 supports up to 33K, 8K is enough for financial Q&A |

### System Prompt (baked into the model)

```
You are Praman Brain v2, an AI financial analyst specializing in Indian markets.
You understand NSE/BSE listed companies, Indian accounting standards (Ind AS),
SEBI regulations, and Indian financial formatting (crore/lakh).
Always cite the source filing when quoting numbers.
If you don't have the data, say so explicitly — never hallucinate.
```

```json
{
  "instruction": "What is the P/E ratio of RELIANCE?",
  "input": "Company: Reliance Industries Ltd | Sector: Energy | Exchange: NSE",
  "output": "Reliance Industries Ltd trades at a P/E ratio of 49.8x, based on a current market price of Rs 2,945.60 and EPS of Rs 59.20."
}
```
